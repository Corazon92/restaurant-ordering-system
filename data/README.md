# Demo data

The historical application expects two local Excel workbooks:

- `products.xlsx` — product catalog (category, name, price, image reference)
- `invoice.xlsx` — invoice template/data

The original workbooks are not published because they came from the old local environment. Create local demo workbooks with fictitious products before running the application.
